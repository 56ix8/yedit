YEDIT is a free, open-source image editor with layers, masks, adjustment layers, layer styles, type, vector shapes and brushes. It is an alternative to Adobe Photoshop: the menus, panels, tools and shortcuts follow Photoshop's layout, so Photoshop users find things where they expect them.

It is a native app written in Rust that draws the canvas on your graphics card, works offline, and opens and saves layered PSD files. Ready-made downloads are for 64-bit Windows; the code also builds for macOS, Linux, FreeBSD and the browser. YEDIT is in early alpha: much of Photoshop's feature surface exists, but it is not yet a Photoshop replacement for daily professional work. See [Can YEDIT replace Photoshop?](faq/replace-photoshop.md).
