YEDIT portable mode

While this file sits next to yedit.exe, YEDIT keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the YEDITData folder beside it, and writes
nothing to %APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move YEDIT with its settings.

Delete this file to use the normal per-user folders instead: %APPDATA%\Yedit for settings
and %LOCALAPPDATA%\Yedit\Recovery for crash-recovery autosaves. If YEDITData can't be
written (for example on a read-only drive), YEDIT says so and uses those folders instead.
